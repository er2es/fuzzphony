# v0.7 PR 2: Synonyms — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) or superpowers:subagent-driven-development. Lean plan (memory: streamlined SDD): files, interfaces and test cases; the implementer writes the code. Steps use checkbox syntax.

**Goal:** Per-index synonyms (mutual groups and one-way rules), expanded on the query side, matched on the stemmed form, no reindex.

**Architecture:** A value object `Synonyms` on `IndexDefinition` (YAML / builder / attribute / exporters). `PostgresEngine` asks PostgreSQL once per search for the stems of the query's words and of the synonym members, then `SynonymExpander` (pure, Core) rewrites the parsed AST: a matching `Term` / `Phrase` leaf becomes `AnyOf(original, alternatives…)` with the alternatives flagged as implied. No compiler changes: the strict, fuzzy, probe and highlight paths already handle `AnyOf`.

**Spec:** [docs/superpowers/specs/2026-10-05-v07-relevance-design.md](../specs/2026-10-05-v07-relevance-design.md) (Part 2 and the Decisions table, which wins).

## Global Constraints

- Entry forms: a group is a list of strings (`[tv, television]`); a one-way rule is the string `laptop => notebook` (several targets separated by `|`); members may be phrases (`solid state drive`). Same forms in YAML `synonyms:`, `IndexBuilder::synonyms(array)` and `#[Searchable(synonyms: [...])]`.
- Matching key = the words of a leaf or member, each stemmed by the index's text configuration (accents folded), joined by a space. A multi-word member matches only a quoted phrase. A prefix term (`tv*`) is never expanded.
- `-tv` excludes the alternatives too; a field-scoped word expands inside the same field.
- Synonyms are not part of the sidecar table or the fingerprint hashes: no schema change, no reindex. Trusted developer input (never from users).
- `Synonyms` is public API (listed in `docs/architecture.md` and `tests/Unit/PublicApiTest.php`); `SynonymExpander` is `@internal`. 100% line coverage of `src/`, PHPStan max, php-cs-fixer, docs in the same PR.
- Branch `v07-synonyms` (stacked on `v07-length-aware-typo-tolerance`). Commit trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Demo changes come at the end of the milestone, not here.

## Review Focus

- A synonym of a synonym is not followed (`a=>b`, `b=>c`: `a` finds `b`, not `c`); a cycle (`a=>b`, `b=>a`) is harmless.
- The exact-title bonus of a query that contains a synonym word still fires (alternatives are not in the bonus text).
- `tv television` (both typed): no duplicate alternatives, no error.
- Stop-word and empty stems (`the`, symbols) do not crash or create a group key.
- An unknown index word costs no extra work when the index has no synonyms (no round trip at all).
- Relaxation: an alternative that matches nothing is never reported in the "ignored words" warning.
