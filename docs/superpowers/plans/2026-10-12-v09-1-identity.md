# 0.9, part 1: Identity (the Actor) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One `Actor` (tenant and user, both optional) that the tenant scope, and later the log and the guards, share; resolved automatically by the bundle's integrations (API Platform filter, Live Component, `fuzzphony:search`), with a missing tenant on a tenant-scoped index shown as a 403.

**Architecture:** Core gets a value object, a resolver interface, `SearchBuilder::asActor()` and a small `SearchGate` that every search goes through when the bundle builds the `Fuzzphony` service (it counts refusals; parts 2 and 3 add the log and the guards to the same class). The bundle adds the `fuzzphony.actor` configuration, two resolvers, the gate service and an exception listener. Nothing changes when nothing is configured.

**Tech Stack:** PHP 8.4, PHPUnit 12, PHPStan max, Symfony 7.4/8.x (`security-core`, `property-access`: suggested, dev-required for tests).

**Spec:** `docs/superpowers/specs/2026-10-12-v09-security-and-analytics-design.md` (part 1 and "Compatibility").

## Global Constraints

- Everything is optional and off by default: no `Actor`, nothing configured means 0.8's SQL, statements and results. The existing test suite must pass unchanged.
- `forTenant()` stays; a tenant-scoped index searched without a tenant and without an actor throws the same `InvalidQuery` message as in 0.8.
- `asActor()`: the last of `forTenant()` / `asActor()` wins; an actor without a tenant never clears a tenant set before; an actor's tenant is applied only on a tenant-scoped index (an application-wide resolver must not break searches of other indexes).
- `ActorRequired extends InvalidQuery` (so `InvalidQuery` loses `final`); HTTP shows it as `AccessDeniedHttpException` (403).
- The tenant in the Live Component is never a client-writable `LiveProp`.
- `symfony/security-core` and `symfony/property-access` are `suggest` only; a setting that needs them fails at container build naming the missing package.
- New public classes are added to `tests/Unit/PublicApiTest.php`; every other new class is `@internal`.
- Code style: `declare(strict_types=1)`, `final readonly` where possible, php-cs-fixer clean, PHPStan max clean, English comments, every change updates README/CHANGELOG (`[Unreleased]`)/docs in the same PR.

## Review Focus

- An application-wide resolver that returns a tenant, used on an index that is not tenant-scoped: must not throw `unexpectedTenant` (Task 2).
- `asActor(Actor::anonymous())` after `forTenant(5)`: the tenant stays 5 (Task 2).
- A tenant that is a string on an int-filtered index, or an object from a property path: a clear `InvalidArgument`, never a silent cast (Task 4).
- A request without a token (anonymous visitor) with a tenant path configured: the anonymous actor, so the tenant-scoped index answers 403, not 500 (Task 4/5).
- The Live Component must not accept a tenant from the client (`LiveProp` audit) (Task 5).
- `fuzzphony:search` with `--user` but no `--tenant` on a tenant-scoped index: a clear message and exit code 1 (Task 5).

```php
declare(strict_types=1);

namespace Fuzzphony\Core\Search;

/**
 * Who is searching: the tenant whose documents the search may see and the user who asks. Both are optional.
 * The tenant scopes a tenant-scoped index (SearchBuilder::asActor()); the user is carried for the search log
```

`src/Core/Search/SearchGate.php`:

```php
<?php

declare(strict_types=1);

namespace Fuzzphony\Core\Search;

use Fuzzphony\Core\Definition\IndexDefinition;
use Fuzzphony\Core\Engine\Engine;
use Fuzzphony\Core\Exception\ActorRequired;
use Fuzzphony\Core\Observability\MetricsCollector;
use Fuzzphony\Core\Observability\NullMetricsCollector;
use Fuzzphony\Core\Query\SearchQuery;
use Psr\Log\LoggerInterface;

/**
 * @internal What every search passes through when the bundle (or an application) builds Fuzzphony with a gate:
 * the refusals are counted and logged here. The search log and the guards (0.9, parts 2 and 3) hook in here too.
 */
final readonly class SearchGate
{
    public function __construct(
        private MetricsCollector $metrics = new NullMetricsCollector(),
        private ?LoggerInterface $logger = null,
    ) {}

    public function search(Engine $engine, IndexDefinition $index, SearchQuery $query): SearchResult
    {
        return $this->guarded($index, $query, static fn(): SearchResult => $engine->search($index, $query));
    }

    public function explain(Engine $engine, IndexDefinition $index, SearchQuery $query, bool $analyze): Explanation
    {
        return $this->guarded($index, $query, static fn(): Explanation => $engine->explain($index, $query, $analyze));
    }

    /**
     * A search made as an actor must have a tenant on a tenant-scoped index. A search without an actor keeps
     * the engine's own check (and message), so nothing changes for code that does not use actors.
     *
     * @throws ActorRequired
     */
    public static function assertActorHasTenant(IndexDefinition $index, SearchQuery $query): void
    {
        if ($query->actor !== null && $index->tenant !== null && $query->tenant === null) {
            throw ActorRequired::forIndex($index->name);
        }
    }

    /**
     * @template T
     *
     * @param \Closure(): T $run
     *
     * @return T
     */
    private function guarded(IndexDefinition $index, SearchQuery $query, \Closure $run): mixed
    {
        try {
            self::assertActorHasTenant($index, $query);
        } catch (ActorRequired $e) {
            $this->metrics->increment('fuzzphony.search.denied', ['index' => $index->name, 'reason' => 'actor_required']);
            $this->logger?->warning('Fuzzphony refused a search: {message}', ['message' => $e->getMessage(), 'index' => $index->name]);

            throw $e;
        }

        return $run();
    }
}
```

```php
<?php

declare(strict_types=1);

namespace Fuzzphony\Bundle\Security;

use Fuzzphony\Core\Exception\InvalidArgument;
use Fuzzphony\Core\Search\Actor;
use Fuzzphony\Core\Search\ActorResolver;
use Symfony\Component\PropertyAccess\Exception\ExceptionInterface as PropertyAccessException;
use Symfony\Component\PropertyAccess\PropertyAccessorInterface;
use Symfony\Component\Security\Core\Authentication\Token\Storage\TokenStorageInterface;

/**
 * @internal The actor read from the Security user with property paths (fuzzphony.actor.tenant: account.id,
 * fuzzphony.actor.user: userIdentifier). No token, or a user without the property: that part is null.
 */
final readonly class PropertyPathActorResolver implements ActorResolver
{
    public function __construct(
        private TokenStorageInterface $tokens,
        private PropertyAccessorInterface $accessor,
        private ?string $tenantPath,
        private ?string $userPath,
    ) {}

    public function resolve(): Actor
    {
        $user = $this->tokens->getToken()?->getUser();
        if ($user === null) {
            return Actor::anonymous();
        }
        $tenant = $this->read($user, $this->tenantPath, 'fuzzphony.actor.tenant');
        $name = $this->read($user, $this->userPath, 'fuzzphony.actor.user');

        return new Actor($tenant, $name === null ? null : (string) $name);
    }

    private function read(object $user, ?string $path, string $setting): int|string|null
    {
        if ($path === null) {
            return null;
        }
        try {
            $value = $this->accessor->getValue($user, $path);
        } catch (PropertyAccessException) {
            return null;
        }
        if ($value === null || is_int($value) || is_string($value)) {
            return $value;
        }
        if (is_scalar($value) && !is_bool($value)) {
            return (string) $value;
        }

        throw new InvalidArgument(sprintf('%s "%s" must read a string or an integer from the user, got %s.', $setting, $path, get_debug_type($value)));
    }
}
```
