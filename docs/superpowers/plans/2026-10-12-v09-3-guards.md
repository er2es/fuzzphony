# 0.9, part 3: Guards (rate limit and authorization) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `SearchGate` that runs guards before every search made as an actor: a per-tenant / per-user rate limit (Symfony RateLimiter) and index- and field-level authorization (Symfony voters); a field the viewer may not see is not searched, ranked, highlighted or suggested from.

**Architecture:** Core gets `SearchGuard`, `Access`, `AccessDenied`, `RateLimited` and `FieldDefinition::$granted`; the gate chains the guards, intersects the allowed fields and hands the engine a `SearchQuery::$allowedFields`. The PostgreSQL engine takes the restricted path only when that is set (every word must also match an allowed field's own column; ranking, bonuses and highlights use the allowed fields only; suggestions and "did you mean" are off). The bundle adds the two guards, their configuration and the 403/429 mapping.

**Tech Stack:** PHP 8.4, PostgreSQL 15 to 18, PHPUnit 12, Symfony 7.4/8.x (`security-core`, `rate-limiter`).

**Spec:** `docs/superpowers/specs/2026-10-12-v09-security-and-analytics-design.md` (part 3, "The restricted path", "Compatibility"). **Depends on:** parts 1 and 2 merged (`Actor`, `SearchGate` with log and redactor, `fuzzphony.search_gate`).

## Global Constraints

- Off by default. Without a guard configured the gate adds nothing; a field without `granted` is visible and searchable by everyone on the unchanged fast path; the restricted path is taken only when `SearchQuery::$allowedFields` is not null. The existing suite passes unchanged, and a test compares the statements of an unrestricted search with and without the guard machinery.
- Guards run only for a search with an `Actor`, in `get()`, `explain()` and `suggest()` (with an actor); a federated search charges the rate limit once (the first index), not once per index. `fuzzphony:search` does not run guards (documented).
- Order: authorization, then rate limit. Refusals: `AccessDenied` (403), `RateLimited` (429 with `Retry-After`); each is counted (`fuzzphony.search.denied` with `reason: authorization`, `fuzzphony.search.rate_limited`), logged and written to the search log (`denied` / `rate_limited`) when the log is on.
- Field-level authorization is exact: a hidden field cannot influence a match, a score, a bonus, a highlight, a count or a suggestion. Filters and facets are not restricted in 0.9.
- `allowedFields` that cover every field of the index mean the unrestricted path (the gate sets null).
- `granted` is not part of the layout: the definition hash and fingerprint ignore it (no reindex or doctor warning when it changes).
- New public classes in `tests/Unit/PublicApiTest.php`: `SearchGuard`, `Access`, `AccessDenied`, `RateLimited`. PHPStan max, php-cs-fixer, docs/README/CHANGELOG `[Unreleased]` in the same PR.
- Dev dependencies: `symfony/rate-limiter` (and `symfony/security-core` from part 1); both stay `suggest`.

## Review Focus

- A word that exists only in a hidden field: no hit, no count, no highlight, no suggestion, no "did you mean" (Task 3, Task 4).
- Two documents that differ only in a hidden field's text: equal scores for a restricted viewer (Task 3).
- The primary field (the exact and prefix bonus field) is hidden: both bonuses are 0 (Task 3).
- `field:word` scoped to a hidden field: nothing; a typo of a hidden field's word: nothing (Task 3).
- A viewer who is granted every field: the same SQL as without any guard (Task 2, Task 6).
- The bundle guard with no token (anonymous request) or no voter for `FUZZPHONY_SEARCH`: denied, not a 500 and not allowed (Task 5).
- A federated search of three indexes charges one token, not three (Task 2).
- The limiter key is missing (an actor with neither tenant nor user): not limited, documented (Task 5).

```php
final readonly class Access
{
    /** @param list<string>|null $fields */
    private function __construct(public ?array $fields) {}

    public static function all(): self
    {
        return new self(null);
    }

    /** @param list<string> $fields */
    public static function only(array $fields): self
    {
        return new self(array_values(array_unique($fields)));
    }

    public function isAll(): bool
    {
        return $this->fields === null;
    }

    public function intersect(self $other): self
    {
        return match (true) {
            $this->fields === null => $other,
            $other->fields === null => $this,
            default => new self(array_values(array_intersect($this->fields, $other->fields))),
        };
    }
}
```

```php
    /**
     * Searches, ranks and highlights only these fields (the guards use it for fields a viewer may not see). A word
     * that exists only in another field finds nothing; calling it again can only narrow the list.
     */
    public function restrictedToFields(string ...$fields): self
    {
        $known = $this->index->fieldNames();
        $unknown = array_values(array_diff($fields, $known));
        if ($unknown !== []) {
            throw new InvalidQuery(sprintf('Index "%s" has no field "%s". Known fields: %s.', $this->index->name, $unknown[0], implode(', ', $known)));
        }
        $allowed = $this->query->allowedFields === null ? array_values(array_unique($fields)) : array_values(array_intersect($this->query->allowedFields, $fields));

        return $this->with($this->query->restrictedTo($allowed));
    }
```

```php
    private function guarded(IndexDefinition $index, SearchQuery $query, bool $charge, \Closure $run): mixed
    {
        try {
            self::assertActorHasTenant($index, $query);
            if ($query->actor !== null && $this->guards !== []) {
                $access = $this->access($index, $query->actor, $charge);
                if (!$access->isAll()) {

                }
            }
        } catch (ActorRequired|AccessDenied|RateLimited $e) {
            $this->refused($index, $query, $e);

            throw $e;
        }

        return $run($query);
    }
```

```php
    /** @throws AccessDenied|RateLimited */
    public function access(IndexDefinition $index, Actor $actor, bool $charge = true): Access
    {
        $access = Access::all();
        foreach ($this->guards as $guard) {
            $access = $access->intersect($guard->check($index, $actor, $charge));
        }
        // a viewer who may see every field takes the unrestricted path
        return $access->fields !== null && array_diff($index->fieldNames(), $access->fields) === [] ? Access::all() : $access;

    private function refused(IndexDefinition $index, SearchQuery $query, \Throwable $e): void
    {
        [$event, $reason, $status] = match (true) {

        $this->metrics->increment($event, $reason === null ? ['index' => $index->name] : ['index' => $index->name, 'reason' => $reason]);
        $this->logger?->warning('Fuzzphony refused a search: {message}', ['message' => $e->getMessage(), 'index' => $index->name]);
        $this->record($index, $query, 0, 0.0, false, $status);
    }
```

`matches()` (the exact side) becomes:

```php
    private function matches(Node $node, string $tsquery, ParameterBag $params): string
    {
        $query = $this->column('ft', sprintf('to_tsquery(%s, %s)', $this->names->regconfig($this->index->text), $params->add($tsquery)));
        $field = $this->scopedField($node);
        if ($this->allowed !== null) {
            $targets = $field === null ? $this->allowed : array_values(array_filter($this->allowed, static fn(FieldDefinition $f): bool => $f->name === $field->name));
            if ($targets === []) {
                return 'false'; // nothing the viewer may see can match
            }

            return sprintf('(s.tsv @@ %1$s AND (%2$s))', $query, implode(' OR ', array_map(fn(FieldDefinition $f): string => sprintf('s.%s @@ %s', $this->names->fieldVector($f->name), $query), $targets)));
        }

        return $field === null
            ? 's.tsv @@ ' . $query
            : sprintf('(s.tsv @@ %1$s AND s.%2$s @@ %1$s)', $query, $this->names->fieldVector($field->name));
    }
```

```php
            ? [$field === null ? 's.fz' : 's.' . $this->names->fieldFuzzy($field->name)]
            : array_map(fn(FieldDefinition $f): string => 's.' . $this->names->fieldFuzzy($f->name), array_values(array_filter($this->allowed, static fn(FieldDefinition $f): bool => $f->fuzzy && ($field === null || $f->name === $field->name))));
        $similarities = array_map(fn(string $c): string => sprintf('%s.word_similarity(%s, %s)', $schema, $norm, $c), $columns);
        $similarity = count($similarities) === 1 ? $similarities[0] : 'GREATEST(' . implode(', ', $similarities) . ')';
        $limit = $threshold ?? ($this->allowed !== null ? Sql::float($this->thresholds->fuzzySimilarity ?? 0.0) : null);
        $recheck = $limit === null ? '' : sprintf(' AND %s >= %s', $similarity, $limit);
```
and keep the rest of the method (the `<%` operator over `s.fz`, and for a scoped word the operator over its column) as it is for the unrestricted path; for the restricted path the condition is `norm <% s.fz` plus the recheck (a restricted viewer's candidate set comes from the combined `fz` index; the recheck decides). `leaf()` already uses `$trigram['similarity']` for the score, so the score follows. When `$this->allowed === []` every leaf compiles to `false`/exact-only through `matches()`, and the leaf score is `CASE WHEN false THEN 1.0 ELSE 0.0 END`: assert it in the unit test.

```php
final readonly class RateLimitGuard implements SearchGuard
{
    public function __construct(private RateLimiterFactory $limiter, private string $per)
    {
        if (!in_array($per, ['tenant', 'user'], true)) {
            throw new InvalidConfiguration(sprintf('fuzzphony.rate_limit.per must be "tenant" or "user", got "%s".', $per));
        }
    }

    public function check(IndexDefinition $index, Actor $actor, bool $charge = true): Access
    {
        $key = $this->per === 'tenant' ? $actor->tenant : $actor->user;
        if ($key === null || !$charge) {
            return Access::all(); // no key, no bucket: an IP limit is Symfony's own business
        }
        $limit = $this->limiter->create((string) $key)->consume(1);
        if (!$limit->isAccepted()) {
            throw new RateLimited(max(1, $limit->getRetryAfter()->getTimestamp() - time()));
        }

        return Access::all();
    }
}
```

```php
final readonly class AuthorizationGuard implements SearchGuard
{
    public function __construct(private AuthorizationCheckerInterface $checker, private string $indexAttribute = 'FUZZPHONY_SEARCH') {}

    public function check(IndexDefinition $index, Actor $actor, bool $charge = true): Access
    {
        try {
            if (!$this->checker->isGranted($this->indexAttribute, $index->name)) {
                throw AccessDenied::forIndex($index->name);
            }
            $allowed = [];
            foreach ($index->fields as $field) {
                if ($field->granted === null || $this->checker->isGranted($field->granted, $index->name)) {
                    $allowed[] = $field->name;
                }
            }
        } catch (AuthenticationCredentialsNotFoundException) {
            throw AccessDenied::forIndex($index->name); // no token: fail closed
        }

        return count($allowed) === count($index->fields) ? Access::all() : Access::only($allowed);
    }
}
```
